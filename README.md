# CLIMB UP

小さなロボットが夕焼けの遺跡を登る 2D アクション。ブラウザだけで動きます（ビルド不要）。

## 遊び方

`index.html` をブラウザで開くだけ。

| 操作 | キー |
| --- | --- |
| 移動 | ← → ↑ ↓ / WASD |
| ジャンプ（長押しで高く） | C / Space |
| ダッシュ（8方向・空中1回） | Shift |
| 壁につかまる・登る | 左クリック長押し |
| やり直し | R |

- 目とアンテナが水色 = ダッシュ可能、灰色 = 使用済み（着地で回復）
- バッテリーに触れるとダッシュ回復
- 壁ぎわでジャンプすると壁キック
- 地上でダッシュ中にジャンプするとスーパージャンプ（斜め下ダッシュならハイパー）
- チュートリアル3部屋 → 上へ登っていくステージ3つ → ゴールの部屋（ゲート）の順に進む
- 歯車を集めつつ、最後の部屋のゲートをめざそう

## ステージの追加

`game.js` の `ROOMS` 配列に部屋を足すだけ。座標はタイル単位（1部屋 40×23 タイル）。

- `solids`: `[x, y, 幅, 高さ]` の壁・床
- `spikes`: `[x, y, 幅]` のトゲ
- `gears` / `batteries`: `[x, y]`
- 右端か上端に開いている所が次の部屋への出口
